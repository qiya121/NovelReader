# iOS 本地小说阅读器 · 产品需求文档（PRD v1.0）

> 本文档面向 AI 编程工具（Claude Code / Cursor / Copilot Workspace）与人类开发者。
> 一个不了解背景的 AI，仅凭本文档应能独立完成 V1 全部开发，不需要再追问产品意图。
> 文中所有"必须/禁止"为硬性约束；"建议"为可偏离但需说明理由的软约束。
> 文档不含实现代码，只含规则、数据结构、算法口径与验收标准。

---

## 0. 项目一句话

一款**纯本地、无账号、无网络**的 iOS 小说阅读器：导入 TXT → 自动切分章节 → 进书架 → 在干净的阅读界面里读书，并提供翻页方式、亮度、背景色、字号、字体、行间距六项阅读设置与书签能力。

---

## 1. 产品定位与设计原则

| 原则 | 落地要求（可验证） |
| --- | --- |
| 界面干净整洁 | 首页只有「导入」和「书架」两件事；阅读界面默认无任何工具栏遮挡正文；一屏内不出现 3 种以上强调色 |
| 单机可用 | 全程不发起任何网络请求，不申请网络权限，不集成任何埋点/广告/统计 SDK |
| 数据全在本地 | 所有用户数据只落在 App 沙盒内，删除 App 即全部清除；禁止上传任何内容 |
| 导入即读 | 从选中文件到进入阅读页，用户操作步数 ≤ 3 步（选文件 → 选章节模式 → 自动打开） |
| 阅读设置即时生效 | 修改任一项设置后，正文在 1 帧内重排且**阅读位置不丢失**（必须回到同一字符偏移处） |

**目标用户**：自己从网上下载 TXT 小说、在 iPhone 上阅读的个人用户。V1 不考虑 iPad、Apple TV、Watch、Mac Catalyst。

## 2. 技术栈与工程约束

| 项 | 决策 | 理由 |
| --- | --- | --- |
| 语言 | Swift 5.9+ | 用户本地开发，Swift 是 iOS 唯一合理选择 |
| 最低系统 | iOS 16.0 | 可用 `TextKit 2`、`NavigationStack`、`.fileImporter`、`PresentationalContentIdentifier` |
| UI 框架 | SwiftUI 为主干；**阅读核心用 UIKit 桥接**（`UIPageViewController` + `UICollectionView`） | SwiftUI 原生没有可靠的逐页文本分页能力，翻页体验必须靠 UIKit |
| 文本分页引擎 | TextKit 2（`NSTextLayoutManager` / `NSTextContentManager`），大文件回退 CoreText 分列 | 需要把长文本按页/按行精确切分并支持字符偏移定位 |
| 存储 | SQLite，通过 `GRDB.swift` 7.x（SPM 引入，锁定版本） | 书籍、章节、书签、进度都需要可索引查询；UserDefaults 装不下章节正文 |
| 文件导入 | SwiftUI `.fileImporter` + `UTType.plainText`（允许多选） | 直接读"文件"App / iCloud Drive / AirDrop 到本地的 txt |
| 依赖数量 | 生产依赖**只允许 GRDB 一个**；禁止再引入任何第三方库 | 减少后续维护与审核风险 |
| 架构分层 | `App` / `Features`(Home, Shelf, Import, Reader, Settings, Bookmarks) / `Core`(Persistence, ChapterParsing, TextPagination, ReadingPreferences) / `Resources` | AI 生成代码时必须按此目录放置，禁止把业务逻辑写进 View |
| 禁止事项 | 禁止引入广告/统计/崩溃 SDK；禁止任何 `URLSession` 调用；禁止要求登录；禁止读写沙盒外路径；禁止在 `Info.plist` 声明网络权限 | 与"纯本地"定位冲突 |

**工程与 Git 约定（本地开发 + GitHub）**

- 仓库为**公开或私有均可**，但 `README.md` 必须说明：纯本地、无网络、数据不出设备。
- 目录：`NovelReader.xcodeproj`、`NovelReader/`（源码）、`NovelReaderTests/`、`NovelReaderUITests/`、`docs/PRD.md`（即本文档）、`CHANGELOG.md`。
- `.gitignore` 必须至少忽略：`xcuserdata/`、`DerivedData/`、`.build/`、`*.xcscmblueprint`、`Pods/`、`.DS_Store`。
- 分支策略：`main` 始终可编译可运行；每个用户故事（US-xxx）开一条 `feature/US-xxx-短名`，完成后 PR 合并，不直接推 `main`。
- Commit 规范：Conventional Commits，`feat|fix|refactor|test|docs|chore(scope): 摘要`，一条 commit 只做一个 US 的一件事。
- 每完成一个 US 必须满足：`xcodebuild build` 通过 + 该 US 的验收标准逐条通过 + 单元测试通过，才允许合并。

## 3. 信息架构与页面清单

```
App 根（TabView，仅 1 个 Tab，即"书架"）
├── P1 首页 / 书架页  ShelfView
│   ├── 导航栏左上角：☆ 星星按钮 → P6 书签列表页
│   ├── 导航栏右上角：＋ 导入按钮 → P2 导入流程
│   └── 书籍卡片 → P3 阅读页（点击）
├── P2 导入流程（系统文件选择器 → P4 章节模式选择弹窗）
├── P3 阅读页 ReaderView
│   ├── 单击正文中央 → 唤起/收起 顶部栏 + 底部工具栏
│   ├── 底部工具栏「设置」→ P5 阅读设置面板（半屏浮层，样式见 §7）
│   ├── 底部工具栏「目录」→ P7 章节目录抽屉
│   └── 底部工具栏「书签」→ 添加/取消当前页书签
├── P5 阅读设置面板（翻页方式 / 亮度 / 背景颜色 / 字体大小 / 字体样式 / 行间距）
├── P6 书签列表页（按书籍分组）
├── P7 章节目录抽屉（章节列表 + 当前章节高亮）

```

**首页严格约束**：首页（P1）除了书架列表本身，只允许出现「导入」和「书架」两个功能入口。**禁止**添加"发现/书城/分类/排行榜/我的/设置"等任何额外 Tab 或入口。收藏状态直接在书架卡片上体现，不设独立页面。

## 4. 数据模型

数据库文件：沙盒 `Application Support/novelreader.db`，通过 GRDB 迁移管理，迁移文件按 `v1_initial`、`v2_...` 顺序命名，**禁止修改已发布迁移**。

### 4.1 `books` 书籍表

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | INTEGER | PK, autoincrement | |
| `title` | TEXT | NOT NULL | 书名，默认取文件名去扩展名；用户可改 |
| `author` | TEXT | NULL | V1 不解析，可为空 |
| `file_name` | TEXT | NOT NULL | 沙盒内备份文件名，如 `books/1_三体.txt` |
| `stored_path` | TEXT | NOT NULL | 相对 Documents 的路径 |
| `encoding` | TEXT | NOT NULL | 实际采用的编码标识：`utf8`/`utf16`/`gb18030` |
| `char_count` | INTEGER | NOT NULL | 正文字符总数 |
| `chapter_mode` | TEXT | NOT NULL | `strict`/`loose`/`none`（导入时用户所选） |
| `is_favorite` | INTEGER | NOT NULL DEFAULT 0 | 是否收藏 |
| `last_chapter_index` | INTEGER | NOT NULL DEFAULT 0 | 上次阅读章节序号 |
| `last_char_offset` | INTEGER | NOT NULL DEFAULT 0 | 上次阅读字符偏移（全书绝对偏移） |
| `last_percent` | REAL | NOT NULL DEFAULT 0 | 阅读百分比，0~1，用于书架展示 |
| `created_at` / `updated_at` | TEXT | NOT NULL | ISO8601 |

索引：`books(is_favorite)`、`books(updated_at DESC)`。

### 4.2 `chapters` 章节表

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | INTEGER | PK | |
| `book_id` | INTEGER | NOT NULL, FK→books.id ON DELETE CASCADE | |
| `index` | INTEGER | NOT NULL | 章节序号，从 0 开始，书内唯一 |
| `title` | TEXT | NOT NULL | 章节标题；`none` 模式下写 `第N段`（见 §5.2） |
| `start_offset` | INTEGER | NOT NULL | 该章正文在**清洗后全文**中的起始字符偏移 |
| `end_offset` | INTEGER | NOT NULL | 结束偏移（不含） |
| `char_count` | INTEGER | NOT NULL | `end_offset - start_offset` |

索引：`chapters(book_id, index)` 唯一。

### 4.3 `bookmarks` 书签表

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | INTEGER | PK | |
| `book_id` | INTEGER | NOT NULL, FK→books.id ON DELETE CASCADE | |
| `chapter_index` | INTEGER | NOT NULL | |
| `char_offset` | INTEGER | NOT NULL | 书签锚定的绝对字符偏移 |
| `excerpt` | TEXT | NOT NULL | 该位置起前 30 个字符的摘要，用于列表展示 |
| `chapter_title` | TEXT | NOT NULL | 冗余存储，删除章节后仍能显示 |
| `created_at` | TEXT | NOT NULL | |

约束：同一 `book_id + char_offset` 只允许一条书签（唯一索引），重复点击即"取消书签"。

### 4.4 `settings` 阅读偏好表（KV）

单行全局默认 + 每本书可覆盖。字段名固定，禁止改名：

`font_size_pt`(默认 19)、`line_spacing_multiplier`(默认 1.6)、`background_color_key`(默认 `paper_white`)、`page_transition`(默认 `slide`)、`app_brightness`(默认 1.0)、`font_family`(默认 `system`)。

> 存储位置：全局默认写 `UserDefaults`（suite 名 `reading.preferences`）；单书覆盖写 `books` 表扩展 JSON 列 `settings_override`（NULL 表示跟随全局）。

## 5. 功能需求

### 5.1 导入（P2）

**流程**：书架右上角「＋」→ 系统文件选择器（允许多选、仅 `.txt`）→ 选中后弹出「章节区分方式」选择（P4）→ 执行导入 → 成功后自动打开第一本新导入的书进入阅读页，其余入库到书架。

**硬性要求**

1. 只接受 TXT 纯文本。文件类型白名单：`.txt`、`.text`；`UTType` 至少包含 `public.plain-text`。其他类型在选择器中置灰不可选。
2. 导入必须把文件**复制**进沙盒 `Documents/books/` 下（命名 `{bookId}_{原文件名}.txt`），不得只保存外部安全作用域引用——用户从"文件"App 导入后原文件可能被移动或删除。
3. 编码识别顺序（必须按此顺序尝试，成功即停）：`UTF-8` → `UTF-16 (LE/BE，按 BOM)` → `GB18030` → 失败。
   - 判定方式：用严格解码（不允许替换字符）尝试；`UTF-8` 解码失败才试下一个。
   - 全部失败：报"文件编码无法识别，请另存为 UTF-8 后重试"，**不得**用乱码内容入库。
4. 文本清洗规则（在切分章节之前执行，顺序固定）：
   - 统一换行符：`\r\n`、`\r` → `\n`；
   - 去掉 UTF-8 BOM 与零宽字符（`U+FEFF`、`U+200B~U+200F`）；
   - 行尾空格清理；连续 3 个以上空行压缩为 1 个空行；
   - 制表符 → 4 空格；
   - **禁止**删除用户正文中的任何字符，只做上述规范化；清洗后的偏移量即为后续所有 offset 的基准，必须在清洗完成后才计算 offset。
5. 进度与失败：单文件 > 20 MB 或解析 > 3 秒，必须显示进度（"正在解析…" + 可取消）；导入过程中取消/失败必须回滚（删除已建 book 记录、已复制文件、已插入 chapters）。
6. 重复导入同一文件（按 SHA-256 内容哈希判定）：提示"该文件已导入，是否打开？"，不得静默生成第二本重复书。

**验收**：UTF-8 与 GB18030 各一份 5 MB 小说能正常导入且无乱码；导入 200 章的书，章节列表数量与源文件实际章数一致；中途取消后书架无残留。

### 5.2 章节区分（P4，三种模式）

导入弹窗必须让用户三选一，标题「区分章节方式」，副标题说明差异，选项文案与口径如下（**正则与规则必须逐字实现，不得自行放宽**）。

#### 模式 A · 严格（`strict`）

- 匹配：**行首可选空格** + `第` + **阿拉伯数字**（1~6 位）或**中文数字**（零一二三四五六七八九十百千两）+ `章`，整行长度 ≤ 30 字符，且该行前后必须为换行或文件首尾。
- 参考正则（严格模式，需配合整行匹配）：`^\s*第[0-9]{1,6}\s*章\s*$` 或 `^\s*第[0-9]{1,6}章.*$`（标题部分允许跟在"章"后，但整行 ≤ 30 字符）。
- **只认"第X章"**。`第X节`、`第X回`、`第X卷`、`楔子`、`序言`、`尾声`、`Chapter 1` 一律**不算**章节行。
- 若全文匹配数为 0：自动降级为模式 C（不区分），并在导入完成时 Toast 提示"未识别到章节，已按整本处理"。

#### 模式 B · 宽松（`loose`）

- 在严格模式基础上，额外接受：
  1. 中文数字：`第一章`、`第一百二十章`；
  2. 阿拉伯数字带空格：`第 1 章`、`第1 章`；
  3. 其他章节量词：`第X节`、`第X回`、`第X卷`、`第X篇`、`第X部`；
  4. 英文：`Chapter 1`、`CHAPTER 01`、`Ch.1`；
  5. 独立成行的常见标志词：`楔子`、`序章`、`引子`、`前言`、`后记`、`尾声`、`番外`、`终章`、`大结局`；
  6. 数字开头 + 分隔符的裸标题行：`1.`、`01 `、`一、`（该行 ≤ 20 字符）。
- 参考正则集合（任一命中即视为章节行）：
  - `^\s*第\s*[0-9零一二三四五六七八九十百千两]{1,8}\s*[章节回卷篇部]\s*.{0,25}$`
  - `^\s*Chapter\s*[0-9]{1,4}\b.{0,25}$`（忽略大小写）
  - `^\s*(楔子|序章|引子|前言|后记|尾声|番外|终章|大结局)\s*.{0,15}$`
  - `^\s*[0-9]{1,4}\s*[\.、\)]\s*\S{1,20}$`
  - `^\s*[零一二三四五六七八九十百千两]{1,8}\s*[、\.]\s*\S{1,20}$`
- **防误判硬约束（必须实现，否则正文会被切碎）**：
  1. 候选章节行长度 > 40 字符 → 丢弃；
  2. 相邻两个章节行之间的字符数 < 100 → 判定为正文误命中，丢弃后一个（保留前一个）；
  3. 识别出的章节总数 > 2000 → 判定为误判，降级为模式 C 并提示；
  4. 章节行必须整行独占（前后是 `\n`），行中间出现"第X章"不算；
  5. 第一章之前的正文若 > 500 字符，自动补一个名为「正文开始前」的章节（`index=0`），避免内容丢失。
- 章节标题 = 该行原文去空格后的整行内容（含"第X章"及后面跟随的书名/副标题）。

#### 模式 C · 不区分（`none`）

- 不做任何章节识别，**但仍必须分页**：
  - 章节表只写 1 条记录：`index=0`，`title = 书名`，`start_offset=0`，`end_offset=全文长度`；
  - 阅读时按 §6 的分页引擎自然分页；
  - 目录抽屉显示"本书未分章"，章节切换按钮置灰不可点。
- 说明：模式 C 不等于"整本书一屏显示"，它只是"没有章节概念"。

**通用**：章节切分结果必须持久化到 `chapters` 表，阅读时不再重复解析；用户可在书籍详情页（长按书架卡片 → 菜单）改选章节模式并"重新解析"，重新解析后进度按字符偏移映射回最近章节。

**验收**：给三份样本文件（`第1章` 阿拉伯数字 / `第一章` 中文数字 / 无任何章节标记），三种模式分别产出预期结果；含"他说：第一章很好看。"这类正文行的文件，宽松模式不得把该行切成章节。

### 5.3 书架（P1）

1. 布局：默认**网格 2 列**卡片（封面占位图 = 书名首字 + 随机柔和底色；V1 不解析封面），支持切换**列表**布局（切换按钮在右上角，状态持久化）。
2. 卡片内容：书名（最多 2 行）、阅读进度百分比、收藏标记（★）、章节数（如 `共 128 章`）。
3. 排序（下拉菜单，四选一，默认"最近阅读"）：最近阅读 / 导入时间 / 书名升序 / 仅看收藏。
4. 长按卡片弹出菜单，必须包含：**打开阅读、收藏/取消收藏、重命名、删除、重新解析章节**。
   - 删除：二次确认弹窗"删除后将同时清除该书的书签与进度，不可恢复"；确认后级联删除 `chapters`、`bookmarks`、沙盒内 txt 文件。
   - 收藏：书架卡片右上角 ★ 单击即可切换，无需进菜单。
5. 顶部搜索框：按书名模糊匹配（不区分大小写），无结果时显示"没有找到相关书籍"。
6. 空状态：插画位 + 文案"书架还空着，点右上角导入一本 TXT 小说" + 一个「导入」按钮（这是首页唯一允许的第二处导入入口）。
7. 导航栏左上角 ☆ 星星按钮 → 进入 P6 书签列表；书架为空时星星按钮置灰。

### 5.4 书签（P3 添加 / P6 管理）

- **添加/取消**：阅读页底部工具栏的书签图标。当前页已存在书签 → 图标为实心并提示"已移除书签"；否则描边样式，点击后提示"已添加书签"。锚点 = 当前页第一个可见字符的绝对偏移。
- **书签列表页（P6）入口**：书架页导航栏左上角星星按钮（用户明确要求此位置）。
  - 单本书时直接进入该书书签列表；多本书时按书籍分组（分组头 = 书名 + 书签数）。
  - 每行：摘录文本（≤ 30 字，超出截断）+ 章节名 + 添加时间。
  - 点击某行 → 跳到阅读页对应位置；左滑 → 删除；顶部 → 清空本书书签（二次确认）。
- 书签上限：单本 500 条，超出提示"书签数量已达上限"。

### 5.5 阅读界面（P3）

**默认状态（干净）**：全屏正文，无导航栏、无工具栏、无页眉页脚装饰；状态栏保留（浅色背景用深色状态栏文字，深色背景用浅色）。

### 5.6 阅读设置面板（P5）

样式必须与截图一致（规格见 §7）。**包含且仅包含以下 6 组**，顺序固定：翻页方式 → 亮度 → 背景颜色 → 字体大小 → 字体样式 → 行间距。

#### ① 翻页方式（三选一，文案必须为「左右」「上下」「连续」）

| key | 文案 | 行为定义 |
| --- | --- | --- |
| `slide` | 左右 | `UIPageViewController` 水平滚动转场，一次一页，有页面指示动画；**不做仿真翻页（paper curl）**，V1 只做平移 |
| `scroll` | 上下 | 整章内容竖向分页滚动：每屏一页，滚到底自动加载下一章顶部，形成连续竖向流；翻页靠手指滚动，无横向动画 |

## 6. 分页引擎规格（AI 实现时的接口口径）

必须实现一个与 UI 无关的 `Paginator` 抽象，供三种翻页模式共用：

- 输入：清洗后的全文字符串、章节区间 `[start,end)`、排版参数（字号、行距、段间距、首行缩进、页边距、屏幕宽高）。
- 输出：`[(pageIndex, charRange)]`，即每页覆盖的字符区间；以及 `offset → pageIndex` 与 `pageIndex → offset` 双向查询。
- 页边距默认：左右各 20pt，上 56pt（预留状态栏+唤起后的顶部栏安全区），下 40pt。
- 章节标题独立成段，字号 = 正文 × 1.35，居中，与正文之间空 1.5 行。
- 排版参数变化后必须重建布局缓存；缓存以 `(bookId, chapterIndex, 排版参数指纹)` 为 key，排版参数指纹 = 字号+行距+背景key+字体+屏幕尺寸 的组合哈希。
- 性能红线：5 MB / 200 章的书，单章（约 3 千字）分页耗时 < 80ms；冷启动打开上次的书到可读状态 < 1.5s；翻页帧率不低于 55fps（iPhone 12 及以上基准机型）。
